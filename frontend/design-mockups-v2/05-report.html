1 Spring Boot 自动装配原理 8.5
题目

请讲讲 Spring Boot 的自动装配原理，它是怎么实现的？

回答摘要

通过 @EnableAutoConfiguration 扫描 META-INF/spring.factories，结合 @ConditionalOnClass 等条件注解按需加载。

面试官评语

核心机制讲得清楚。但缺少对 @Import 与 ImportSelector 的展开，对 Spring Boot 3 改用 AutoConfiguration.imports 的变化不熟，建议补齐。
