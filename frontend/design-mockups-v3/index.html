令牌输入页

/login

入场卡式登录：宋体标题 + 红色题线 + 等宽字体令牌输入。
01b

令牌错误态

/login (error)

令牌无效：红色输入框边 + 居中红色提示行。
02

历史会话首页

/

纸色侧栏名册 + 主区空状态引导。状态用文字标签：墨蓝进行中 / 绿已出报告 / 赭待生成。
03

新建面试页

/new

面试配置单：一二三大题式分节（简历 / JD / 配置），方角分段选择按钮。
04

面试聊天页（核心）

/interview/:id

顶栏答题卡进度格 + 题号方框对话流；面试官消息为方框题号卡片，你的作答为墨线答块，Agent 活动流收在题卡下方。
05

复盘报告页

/report/:id

评定表式报告：红笔圈分大分数 + 蓝黑维度进度条 + 逐题回顾 + 红底批注评语。
06

流式中间态

/interview/:id (streaming)

面试官生成中：红点提示条 + 朱红光标闪烁 + 活动流末项运行中，发送变为红色停止。
07

报告生成中

/report/:id (generating)

正在批阅：旋转圆环 + 方框勾选式分步进度（消息汇总 / 逐题评分 / 生成建议 / 汇总输出）。
提案说明：V3 借用中文试卷的视觉语言——纸白卷面、墨色正文、蓝黑墨水交互色，朱砂红只用于批改与终止语义（顶栏红线、红笔圈分、逐题得分、批注评语、结束面试/停止）。签名元素三处：主顶栏下的红头文件线、面试页答题卡进度格、报告页红笔圈分。字体分工：微软雅黑承担全部中文（Bold 区分层级）、Georgia 写分数数字、Consolas 放数据——衬线宋体与楷体因屏幕小字号发虚已移除，试卷感完全由结构与红笔语义承担。硬约束全部保持：无 emoji、无渐变、无插画、扁平、桌面端。2026-10-31 用户评审未采用（字体观感不佳），仅存档参考。
