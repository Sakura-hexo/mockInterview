1 Spring Boot 自动装配原理 8.5
题目

请你说说 Spring Boot 的自动装配原理，它是怎么实现的？

你的回答摘要

通过 @EnableAutoConfiguration 扫描 META-INF/spring.factories，结合 @ConditionalOnClass 等条件注解按需加载。

面试官评语
核心机制讲得清楚，能提到 spring.factories 和条件注解。但缺少对 @Import 和 ImportSelector 的深入展开，对 Spring Boot 3 的 AutoConfiguration.imports 新文件路径不熟悉，建议补充。
2 Redis 缓存穿透 / 击穿 / 雪崩 7.0
题目

说说缓存穿透、缓存击穿、缓存雪崩的区别，以及项目里怎么解决的？

你的回答摘要

穿透用布隆过滤器拦截非法 key；击穿用互斥锁重建缓存；雪崩设置过期时间加随机值。

面试官评语
概念区分准确，方案也是标准答案。但被追问"布隆过滤器误判率如何权衡"时回答较模糊，暴露出对布隆过滤器底层 bitmap 与 hash 函数数量计算理解不深。
3 MySQL 索引下推与最左前缀 6.5
题目

解释索引下推（ICP）和最左前缀原则，联合索引 (a,b,c) 在 where a=1 and c=3 中能用到哪些列？

你的回答摘要

最左前缀要求从最左列开始匹配，跳列会失效。联合索引中 a 能用，c 不能。

面试官评语
最左前缀答对了一半，但对 ICP 的理解停留在名字层面，没说清"在存储引擎层过滤 vs 在服务层过滤"的本质差异。MySQL 8 的 Skip Scan 完全没提到。
