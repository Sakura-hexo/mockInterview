### 7d SSE 流式

| 文件 | 内容 |
|---|---|
| agent/StreamChunk 新增 | sealed 接口：Delta 文本增量、Final 终稿快照（fullText 恒等于增量拼接、带 toolCalls） |
| agent/TurnListener 新增 | 增量回调，Web 层转发 SSE |
| agent/AgentRuntime | 端口改流式为主动方法，generate 降级为默认实现（取最后一个 Final） |
| infra/AgentScopeRuntime | streamEvents 映射：TEXT_BLOCK_DELTA 转 Delta、TOOL_CALL_START 计数、AGENT_RESULT 出 Final（fullText 取增量拼接，无增量回退终稿文本，用量取终稿 usage）；思考块与工具事件不转发 |
| agent/Supervisor | 监听版 chat；题型按工具信号推导：无工具 FOLLOW_UP、有工具首题 QUESTION 其余 NEXT，闲聊固定 FOLLOW_UP 防推进题号；SupervisorReply 增 action；createSession 增用户与配置重载 |
| api/ChatStreamService 新增 | SseEmitter 320 秒超时；事件构造集中此处（message/action/metrics/done/error）；无增量的意图整段补发一次 message；客户端断线静默吞发送失败不取消生成；SseSender 接口供单测替换 |

## 已知边界

- action 工具信号启发式：调题库工具出的扩展追问会推进题号（真机第 3 题即此边界），计数安全不崩溃，LLM 精分类留作后续增强
- IAB 测试环境原生 confirm 接受后 JS 续行不完整，end 接口幂等性由 curl 补验
- 会话 detail 的 direction 取 JD 解析文本（如"Java 后端开发工程师"），config.direction 枚举未单独落列，可由 JD 推导
