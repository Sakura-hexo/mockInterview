# AI 模拟面试平台 步骤03 实现

作者:开发执行 AI（ZCode）| 创建时间:2026-10-31 19:40

对应计划：`plans/2026-10-31/AI模拟面试平台-开发指令-步骤03.md`。

## 1 本批次做了什么

- 依赖：pom 新增 `tika-core` 与 `tika-parsers-standard-package`（3.3.0，指令中误写的 tika-parsers-standard 是无 jar 的父 POM，已修正）与 `spring-boot-starter-test`（test scope，项目首个测试依赖）
- `session` 包四个无框架 record：SessionConfig、ReportScore（0 到 10 校验）、ReportItem（得分校验）、InterviewReport，字段以接口文档第 3 节为准
- `infra/LlmCaller` 端口加 `infra/AgentLlmCaller` 生产实现（一次性会话智能体，每次新 sessionId，不携带历史）
- `infra/StructuredOutputInvoker`：统一结构化输出调用器——追加格式要求、剥离 markdown 围栏、零宽字符与尾逗号本地修复、解析失败带具体原因回填重试（默认 3 次）、调用数重试数失败数与耗时的 AtomicLong 计数（步骤 8 换 Prometheus）
- `rag/QuestionSearcher` 检索端口，`MilvusQuestionStore` 实现之（search 即混合检索）
- `tool` 包五类工具与注册中心：
  - ResumeParseTool：纯文本直通；PDF 上限 5MB 经 Tika 提取；空文本与扫描件显式抛异常
  - JdParseTool：经调用器产出 JdProfile（方向、技能、加分项）；LLM 失败或缺 skills 字段均显式降级为原文整体作唯一要点并打日志
  - QuestionBankTool：包检索端口与 SearchTiers 分档，输出面试官用题目文本块，无命中返回提示语
  - CompanyInfoTool：P1 占位
  - ReportExportTool：InterviewReport 转 Markdown（评分表、逐题回顾、建议三段）
  - Toolbox：按名注册获取、计时日志、invokeOrFallback 兜底包装（fallback 调用不要求注册）
- `tool/ToolCliRunner`：jd 子命令真机冒烟入口

## 2 遇到的问题与解决方式

| 问题 | 解决方式 |
|---|---|
| tika-parsers-standard 坐标不存在 | 查本地仓库确认正确聚合包名为 tika-parsers-standard-package |
| StringBuilder 无 strip 方法 | 两处改 sb.toString().strip() |
| 测试 lambda 与 QuestionSearcher 双参接口不匹配 | 补第二参数；SearchTiers 常量改 public 供跨包测试引用 |
| Toolbox 兜底调用被未注册校验挡住（单测暴露） | 计时逻辑抽为私有 timed，invokeOrFallback 的 fallback 路径不走注册校验 |
