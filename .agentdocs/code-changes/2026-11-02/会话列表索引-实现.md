# 会话列表索引-实现

作者:Sakura | 创建时间:2026-11-02 12:25（方案：`.agentdocs/plans/2026-11-02/会话列表索引-优化方案.md`）

## 变更清单

- `sql/session-schema.sql` — `idx_session_user` 从 `(user_id)` 升级为 `(user_id, created_at)`
- `infra/SchemaMigrations.java` — `createIndex` 单列补建替换为 `ensureIndexColumns`
  幂等列集迁移：查 information_schema 按序取该索引列集，与目标不一致则 DROP 后
  CREATE，一致则跳过（新装库与已升级库均零操作）

## 验证记录

- `mvn test`：109 全绿
- 存量库迁移实测（重启触发）：`SHOW INDEX FROM t_session` 见 idx_session_user
  两列（user_id 第 1、created_at 第 2）
- EXPLAIN 前后对比："我的会话列表"查询 `WHERE user_id=? ORDER BY created_at DESC
  LIMIT` 从 `Using filesort` 变为 `Backward index scan`
- 列表接口回归正常（按 created_at 倒序返回）
