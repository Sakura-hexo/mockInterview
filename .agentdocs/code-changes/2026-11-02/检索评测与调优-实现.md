`检索评测-原始数据.txt`。

## 三个结论（均与方案预期有出入，以数据为准）

1. **压制问题已自愈，题干加权实验取消**：AG-010 与 RG-015 两个已知压制 case
   在 152 题库上全部第一名命中（混合高频 10/10）——题库扩容稀释了概念题的
   词频优势。且题干加权救不了口语化：查询里没有术语可加权（E-022 接口慢、
   E-023 变量看不见是查询侧语义鸿沟）。
2. **改写器上限 +27% hit@1，但不进生产热路径**（方案既定决策）：接进
   candidatesFor 会给面试官轮加回一次 fast 档模型往返，抵消预检索优化。
   改写器保留在 CLI 诊断与评测口径，量化记录在此。
3. **阈值定标是负结果，不设阈值**：top1 加 top2 分差与 top1 绝对分均无法分离
   正负例——负例 E-044（K8s 调度 → OS-003 进程调度）双路同现拿分差 0.0167，
   大于多数正例；正例 E-027 第一名命中但分差为零。任何简单阈值在 45 条上
   误判 5 到 7 条。题库外兜底由面试官提示词"候选题不合适自行出题"承担；
   稠密分阈值（负例密集区约 0.46 到 0.54）记为题库扩容后的重评候选。
