## 简历终版（2026-10-29 定稿）

```text
项目名称：AI 模拟面试官（多智能体应用）
开源地址：github.com/<你的用户名>/ai-mock-interview（做完后填）

项目描述：独立开发的 AI 模拟面试系统，基于 AgentScope-Java 实现多智能体
  协作面试，支持简历驱动的多轮出题与追问、题库混合检索、面试后结构化
  复盘，针对长会话与模型调用不稳定做了上下文压缩与容错设计。

个人职责：
1. 自建 Java 后端题库并实现混合检索：题目经分块与通义 Embedding 向量化
   写入 Milvus，检索采用关键词与语义双路召回、RRF 融合排序；搭建百条
   评测集，实测混合召回对比纯语义检索的命中率提升 X%。
2. 基于 AgentScope-Java 子智能体机制编排路由、面试官、简历分析、复盘
   四类智能体，Supervisor 按意图与面试状态统一调度；封装简历解析、
   岗位解析、题库检索、信息查询、报告导出五个业务工具，统一注册与
   异常兜底。
3. 治理面试长会话：会话消息 Redis 热存、MySQL 持久化，上下文组装采用
   滑动窗口与 LLM 摘要压缩控制单轮输入 Token，支撑单场数十轮追问
   （Token 开销下降 X%）。
4. 建设稳定性与可观测：Resilience4j 对模型接口重试与熔断，熔断后降级
   轻量模型；复盘报告异步生成；AOP 埋点将延迟、Token 消耗、召回命中率
   上报 Prometheus 与 Grafana（P95 延迟从 X 降至 Y ms）。
5. 设计面试场景安全防线：模型密钥仅经环境变量注入并以 gitignore 隔离，
   接口 Bearer 鉴权防匿名调用；面试官角色由系统提示词锁定，对抗性输入
   按面试内容处理，防止提示注入绕过评分。

技术栈：Java 21、Spring Boot 3.4、AgentScope-Java、MySQL、Redis、Milvus、
  Resilience4j、Prometheus、Grafana、Docker、通义千问
```
