## 前置核验结论（2026-10-31 架构师完成，全部 javap 本地仓库 jar，不必重复核验）

- `ReActAgent.Builder` 已核验支持：`maxIters(int)`、`toolkit(Toolkit)`、`enableMetaTool(boolean)`、`fallbackModel(Model)`、`stateStore`、`conflictPolicy`、`defaultSessionId`、`hooks/middleware`、`longTermMemory`、`permissionContext`
- **权限收敛天然成立**：ReActAgent 及其 Builder 字节码中零内置工具引用——不传 toolkit 即无任何工具（禁文件、禁 shell 无需额外配置）；面试官只注册题库工具，`enableMetaTool(false)` 显式关闭
- **@Tool 注解为方法级**：`@Tool(name="...", description="...")`，参照内置 `ReadFileTool.viewTextFile`；工具方法返回 `Mono<ToolResultBlock>`，构造用 `new ToolResultBlock(String id, String name, ContentBlock)`（三参构造器已核验）；`Toolkit.registerTool(实例)` 自动发现注解方法
- **风险点须小步实验**：注解方法的参数名绑定机制未核验（反射参数名可能退化为 arg0）。先写一个单参数工具方法真机跑通确认参数绑定正常，再定型
- 路由、简历分析、复盘点评均为单次结构化输出：直接复用步骤 3 的 `StructuredOutputInvoker` 加 `LlmCaller`，**不需要构建 ReActAgent**；只有面试官与闲聊走对话型智能体

### 4a AgentRuntime 端口与实现

- `agent/AgentRuntime` 端口（后端架构方案 3.1 的落地，interrupt 留到步骤 7 SSE 时补）：
  - `Mono<String> generate(String role, String sessionId, String systemPrompt, String userInput)`
  - `String modelName(String role)`
- `infra/AgentScopeRuntime` 实现：按 role 构建 ReActAgent——`interviewer`（maxIters 3、toolkit 挂题库工具、stateStore 跨轮记忆，同一 sessionId 累积上下文）、`chat`（maxIters 1、无工具，每次新 sessionId 一次性响应）；系统提示词由调用方传入，端口不管上下文组装
- **FakeAgentRuntime**（test 包）：按 sessionId 返回预设回复，记录收到的 systemPrompt 与 userInput 供断言——编排单测全部不调真实模型

### 4b 题库工具的智能体挂载

- `QuestionBankTool` 增加注解方法：`@Tool(name = "search_question_bank", description = "按查询检索面试题库，返回最相关题目列表")`，入参一个 String query，返回 `Mono<ToolResultBlock>`，内部调用 `retrieveAsText`
- 先用单参数工具真机实验确认参数绑定，再进入 4c

### 4c 编排与内存会话状态

- `agent/Intent` 枚举：INTERVIEW、CHAT、REPORT
- `agent/Router`：意图分类双保险——关键词规则兜底优先（出现「复盘」「报告」「结束面试」映射 REPORT，命中即返回不调模型），未命中走 StructuredOutputInvoker 的 few-shot 分类输出 `{"intent":"..."}`
- `agent/InMemorySessionState`：内存版会话状态（resumeDigest、jdDigest、askedQuestions 已问题目摘要列表、round 轮次），标注步骤 5 将换持久化实现，字段以接口为准
- `agent/Supervisor`：
  - `createSession(resumeText, jdText)`：简历文本直通加 JD 经 JdParseTool 提要点，简历结构化摘要点经 invoker 生成 resumeDigest，写入新状态并返回 sessionId
  - `chat(sessionId, userText)`：route 分流——INTERVIEW 走 `runtime.generate("interviewer", ...)`（系统提示词由 Supervisor 组装：角色锁定声明加简历要点加 JD 要点加已问题目防重复清单），完成后把面试官本轮输出摘要追加进 askedQuestions；CHAT 走 `runtime.generate("chat", ...)` 轻量回应；REPORT 返回占位话术（复盘报告在面试结束后生成，本步不实现真实报告）
- `agent/Prompts`：集中四个角色的提示词常量（角色锁定声明沿用步骤 1 的对抗性输入处理条款，REPORT 话术明确说功能在面试结束后生成）
